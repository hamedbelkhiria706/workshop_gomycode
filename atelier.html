L'Atelier Pratique : Feuille de Route

Mettre les mains dans le code : concevoir, entraîner et valider votre modèle

Les 3 étapes clés du projet

Voici les étapes guidées que chaque participant ou équipe réalise durant l'atelier :

1. Trouver les données

Télécharger un jeu de données de ventes public (par exemple sur Kaggle : Store Sales Forecasting ou données de boulangerie/retail). Nettoyer les données et repérer les tendances saisonnières.

2. Construire un modèle

Développer un premier modèle de prévision simple (moyenne mobile, régression linéaire, ou Random Forest). L'enrichir ensuite avec des variables calendaires (jours fériés, weekend, météo).

3. Mesurer et présenter

Comparer les prévisions aux ventes réelles sur un jeu de test. Calculer l'erreur moyenne (MAE/RMSE) et créer un graphique visuel clair à présenter au reste de la promotion.

Livrables attendus pour l'atelier

📋 Votre checklist de fin de session :

  • Jeu de données préparé : Fichier CSV nettoyé comportant les dates et les quantités vendues par jour.
  • Notebook ou Script Python : Code reproductible chargeant les données, entraînant le modèle et effectuant la prédiction.
  • Graphique d'évaluation : Courbe superposant les ventes réelles et les prévisions générées par l'IA.
  • Métrique de performance : Score d'erreur (MAE) chiffrant l'écart moyen par rapport à la réalité.
  • Pitch de 5 minutes : Présentation du cas d'usage, des résultats obtenus et des recommandations pour le commerçant.

🚀 Prêt à coder ?

Ouvrez votre environnement de développement (Jupyter Notebook, Google Colab ou VS Code) et commencez par explorer le dataset fourni pour la session.
